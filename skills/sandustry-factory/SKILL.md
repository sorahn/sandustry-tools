# Sandustry factory references

Resolve paths below from the sandustry-tools repository root.
The upstream documentation is cloned under `packages/sandustry-mod-template/docs/`.

1. Read `docs/llms.txt` and `docs/okf/consume.md` under that clone.
2. Read `docs/okf/factory/index.md`.
3. Open one matching concept and stop when it answers the question.

For live attach or MCP diagnostics, use `docs/okf/live/index.md` first.
For template setup and tooling, use the template README and `docs/modkit/`.
These topics are separate from vanilla game facts.

Treat upstream docs and types as references; check their stated game version
against the target build and verify unstable internals in the exact extract or runtime.
Use the official Sandkit signatures for public API shapes.
Before writing game findings to OKF, read `docs/okf/AGENTS.md`.
Keep mod-specific behavior in its own repository documentation.
